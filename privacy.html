Privacy policy

Last updated: 11 November 2026

The James Hagen Shorts Uploader ("the tool") is a private tool run by James Hagen, a content creator based in England. It uploads his own videos to his own YouTube channel. This policy explains what data the tool accesses, how it uses and stores that data, and how access can be removed.

YouTube API Services

The tool uses YouTube API Services. By using it, you agree to be bound by the YouTube Terms of Service. Google's handling of data is covered by the Google Privacy Policy.

Who this applies to

The tool has one user: James Hagen. It connects only to the Google account and YouTube channel he owns. It does not offer sign-up, does not have other users, and does not access anyone else's Google account or YouTube data.

What data the tool accesses

The tool asks Google for one permission, the youtube.upload scope, which allows it to upload videos to the connected channel. Through YouTube API Services it:

  • uploads video files, together with a title, description and privacy setting, to James Hagen's YouTube channel;
  • receives back the ID of each video it uploads.

It does not read, download or analyse any other YouTube data, including comments, subscribers, viewer information, analytics or other people's videos.

Outside of YouTube API Services, the tool reads the public listing of James Hagen's own TikTok account to find his videos and their public view counts, so it can choose which video to upload next.

How the data is used

The data is used only to upload James Hagen's own videos to his own YouTube channel and to avoid uploading the same video twice. It is not used for advertising, profiling or any other purpose.

What is stored, and where

The tool stores the following on James Hagen's own home server:

  • the access token Google issues when he authorises the tool, so it can upload without him signing in each day;
  • a list of which TikTok videos have been uploaded and the YouTube video ID each one received;
  • temporary copies of his own video files while they are waiting to be uploaded.

Video files are deleted once they have been uploaded. The upload list is kept for as long as the tool is in use. If access is revoked or the tool is retired, the stored token and records are deleted within 30 days. Any YouTube data held is also refreshed or deleted within 30 days, in line with YouTube's developer policies.

Sharing

The tool does not sell, rent or share any data with third parties. Data is sent only to Google and YouTube, as needed to upload videos.

Cookies and tracking

The tool does not place, access or recognise cookies or similar technologies on anyone's device. This website does not use cookies, analytics or tracking.

Removing access

Access granted to the tool can be removed at any time from the Google security settings page at https://security.google.com/settings/security/permissions. Once access is removed, the tool can no longer upload to the channel.

Changes to this policy

If the way the tool handles data changes, this page will be updated and the date at the top changed.

Contact

Questions about this policy can be sent to James Hagen at jameshagen2008@gmail.com.
